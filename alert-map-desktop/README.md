# Мапа Тривог — настільний застосунок (v1.1)

Інтерфейс у стилі iOS (скляні панелі, нижня панель вкладок, списки як у «Параметрах»), світла й темна теми — за системою.
Працює у треї, стежить за тривогами навіть із закритим вікном, показує сповіщення системи й запускається разом із Windows.
Без інтернету показує останні відомі дані з позначкою про застарілість.

## Як отримати .exe
**Спосіб 1 (на вашому ПК з Windows).** Встановіть Node.js LTS, розпакуйте архів і двічі клацніть `build-exe.bat`.
Через кілька хвилин відкриється папка `dist` з двома файлами:
- інсталятор — ставить застосунок, створює ярлики й дозволяє автозапуск із Windows (рекомендовано);
- портативна версія — запускається подвійним клацанням без встановлення (автозапуск із Windows у ній не працює).

**Спосіб 2 (без Node.js на ПК).** Завантажте проєкт на GitHub, відкрийте Actions → build-windows → Run workflow.
Готовий .exe буде у «Artifacts» цього запуску.

Для перевірки без збірки: `start.bat`.

## Запуск (вручну)
1. Встановіть Node.js (LTS): https://nodejs.org
2. У цій папці: `npm install`
3. `npm start` — запуск для перевірки
4. `npm run dist` — інсталятор Windows у папці `dist/`

## Справжні дані
Токен: https://alerts.in.ua/api-request. Вставте його у «Налаштування» → «Зберегти». Без токена працює демо-режим.

## Захист
- Вікно ізольоване: sandbox, contextIsolation, без Node.js; суворий CSP; без доступу до мережі, дозволів і навігації.
- Мережу використовує лише основний процес — тільки HTTPS до api.alerts.in.ua, без редіректів, з таймаутом і лімітом розміру відповіді, з перевіркою формату.
- Токен зашифровано засобами ОС (DPAPI/Keychain) і ніколи не повертається у вікно. Якщо шифрування недоступне — токен живе лише в пам’яті.
- PIN (4–8 цифр, scrypt) блокує зміну токена й налаштувань; розблокування діє 5 хвилин і знімається при згортанні в трей; 5 хибних спроб — пауза 60 с.
- Усі IPC-виклики перевіряють відправника й дані.
- У збірці вимкнено RunAsNode, NODE_OPTIONS та інспектор (Electron Fuses); застосунок завантажується лише з asar.
- Файли налаштувань і кешу — у профілі користувача з обмеженими правами.
- Перед релізом: `npm run audit`, оновлюйте Electron, підпишіть інсталятор сертифікатом підпису коду.

## Нотатки
- Закриття вікна згортає застосунок у трей; повний вихід — меню іконки в треї.
- Перевірте формат відповіді API на alerts.in.ua: мапінг областей і типів тривог — `toLevels` у `main.js`.
- Застосунок допоміжний — не вимикайте офіційні оповіщення.
